# 🚀 Copy (Memcpy) 커널 벤치마크 (Baseline)

- **작성일:** 2026-02-16
- **디바이스:** NVIDIA RTX 3060
- **커널 타겟:** copy_f32, copy_f16

---

## 1️⃣ 성능 요약 (Streaming Baseline)

> Purpose: 이 장비에서 관측 가능한 **순차 DRAM 스트리밍 성능 기준점(Baseline Bandwidth)** 측정.  
> 다른 Memory Bound 커널(Add, Adam 등)의 목표 성능은 이 수치에 근접해야 한다.

| 데이터 타입 | 입력 크기 | 실행 시간 | 대역폭 (GB/s) |
| :--- | :--- | :--- | :--- |
| F32 (4B) | 4096² (16M) | 0.450 ms | **298.16** |
| F16 (2B) | 4096² (16M) | 0.231 ms | 291.12 |

---

## 2️⃣ 분석

### 📊 F32 Baseline (≈298 GB/s)

- 순차 Read + Write 패턴
- Coalesced memory access
- DRAM 스트리밍 성능의 실측 기준점

이 값은 본 장비에서 관측된 **Streaming DRAM Baseline**으로 사용한다.

---

### 📉 F16이 약간 낮은 이유 (~2.4%)

- half(2B) 스칼라 접근은 float(4B) 대비
  - 명령 발행 측면에서 미세한 오버헤드
  - 트랜잭션 정렬/병합(coalescing) 효율 차이
- 그 결과 약 2~3% 수준의 대역폭 차이가 관측됨.

이는 구조적 한계라기보다는 **스칼라 접근 방식의 미세한 비효율**로 해석할 수 있다.

---

## 3️⃣ 벡터화 가능성

- F16을 `float4` 또는 `half8` 단위로 벡터화하면
  - 명령 발행 수 감소
  - 트랜잭션 효율 개선
  - F32 baseline과 동등하거나 소폭 상회 가능

---

## 4️⃣ 프로젝트 성능 기준 (Baseline-relative)

Memory Bound 커널은 다음 기준으로 평가한다:

- **Excellent:** Copy(F32) baseline 대비 ≥ 95%
- **Good:** 90 ~ 95%
- **Needs Investigation:** < 90%

이번 Copy 커널은 이 장비에서의 DRAM 스트리밍 기준점을 정의하였다.
